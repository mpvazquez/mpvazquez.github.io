How I work
CSS is the foundation

CSS-first is an architectural choice, not just a styling preference. Less JS at runtime means faster initial paint, simpler component state, and cleaner cross-browser behavior. I default to CSS for theming, transitions, and state where I can.

Accessibility is architecture

WCAG 2.2 AA isn't a polish pass. It shapes semantics, focus order, keyboard flows, and the component API from the first line of code.

Performance is a feature

Core Web Vitals translate directly to revenue. I default to CSS over JS, lazy-load below the fold, right-size imagery, and measure before shipping.

Engineering shaped by design

The seam between design and engineering is where systems hold up or fall apart. I pressure-test interaction patterns with designers and shape the specs before they reach implementation.
